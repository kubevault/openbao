# CouchDB storage backend

The CouchDB storage backend is used to persist OpenBao's data in
[Apache CouchDB][couchdb].

:::warning

**Note**: This backend does not support High Availability. CouchDB also has
no native multi-document transaction or rollback primitive, so unlike the
PostgreSQL and MySQL backends, this backend does not implement OpenBao's
transactional storage interface either.

:::

```hcl
storage "couchdb" {
  endpoint = "http://127.0.0.1:5984/openbao"
  username = "openbao"
  password = "..."
}
```

## `couchdb` parameters

- `endpoint` `(string: <required>)` – Specifies the full URL to the CouchDB
  database to use, including the database name (OpenBao does not create the
  database itself; it must already exist). May also be specified via the
  `COUCHDB_ENDPOINT` environment variable.

- `username` `(string: "")` – Specifies the CouchDB username to connect
  with. May also be specified via the `COUCHDB_USERNAME` environment
  variable.

- `password` `(string: "")` – Specifies the CouchDB password to connect
  with. May also be specified via the `COUCHDB_PASSWORD` environment
  variable.

- `max_parallel` `(string: "128")` – Specifies the maximum number of
  concurrent requests to CouchDB.

## `couchdb` examples

### Custom database

```hcl
storage "couchdb" {
  endpoint = "https://couchdb.example.com/openbao-prod"
  username = "openbao"
  password = "..."
}
```

## Manually creating the database

OpenBao does not create the target database for you; it must already exist
before starting OpenBao:

```shell-session
$ curl -X PUT -u openbao:password https://couchdb.example.com/openbao
```

[couchdb]: https://couchdb.apache.org/
